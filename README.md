# Luck Serviços

Página de vendas estática com banners, seleção interativa de planos e links de pagamento online e atendimento pelo WhatsApp.

## Publicar na Vercel

Importe este repositório e use o nome `luckservicos`. Selecione **Other** como framework, mantenha o diretório raiz e deixe os comandos de instalação e build vazios. Os arquivos estão na raiz; não há dependências.

## Arquivos

- `index.html`: página e estilos responsivos
- `interactive.js`: seletor de planos, animações e navegação
- `hero.webp` e `plano-*.webp`: quatro banners em WebP
- `vercel.json`: configuração de hospedagem estática
